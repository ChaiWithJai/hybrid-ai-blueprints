# Agents' Last Exam economic frontier study

The study helps PrismML select professional work that is valuable and suitable
for an AI agent. It does not measure model or blueprint performance.

## Agents' Last Exam

[Agents' Last Exam](https://agents-last-exam.org/) evaluates full agent systems
on long professional tasks with verifiable outcomes. A system keeps its model,
harness, tools, memory, and action loop. The benchmark scores the artifacts the
agent leaves in the environment.

The unit under test is therefore an agent system, not a model response. Hybrid
AI Blueprints adopts the same unit.

## Economic frontier method

The August 18, 2026 study reviewed 153 published tasks and estimated their
economic value. The model used loaded labor cost, task time, annual frequency,
risk, review burden, compute cost, current success, target success, market gap,
and deployment readiness.

The workbook reported:

| Measure | Result |
| --- | ---: |
| Published tasks | 153 |
| Build now opportunities | 14 |
| Median opportunity score | 55.2 |
| Modeled target net annual value | $4,842,129 |
| Average assumed Bonsai fit | 52.0 |

The dollar value is a work unit estimate across the selected tasks. It is not a
revenue forecast.

## How the study is used

The study selects jobs for discovery and evaluation. Each selected job must
then receive a task contract, a complete blueprint, an evaluation, and human
review. Buyer research must replace the workbook assumptions before a pricing
or investment decision.

The deal room use case was selected because the work needs structured document
analysis, citations, calculations, review routing, and a private deployment
option.
