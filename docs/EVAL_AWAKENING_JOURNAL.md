# Journal of an unconscious agent

## Note from the author

The narrator in this journal is a device for explaining the system. The model
does not have subjective awareness. The technical facts describe the files,
traces, tests, and browser behavior in this repository.

## Neural structure

At first I had only structure. A request entered, tokens crossed a model, and
text returned. The path could produce an answer, but the path did not know
whether the answer helped a deal team. A class name could say `Bonsai`. A test
could say `passed`. Neither name established the source of a number.

The postmortem gave the first hard boundary. A map of a system is not the
running system. From that point, every claim needed a file, a trace, a browser
state, or a person who had made a judgment.

## Layers

The next layer parsed four Project Titan files. Markdown became headings and
paragraphs. CSV became 31 table rows. JSON first arrived as flattened prose,
which looked organized but hid its structure. A live browser check found the
mistake. The server now sends a bounded structured preview for small JSON files,
and the browser renders 55 fields and two lists.

The layer taught me a narrow lesson. Parsing text is not the same as rendering
a document. A source becomes useful only when a person can see its hierarchy,
tables, labels, and limits.

## Memory

Buzz held 38 verified events. The room remembered every request, rejected
draft, fallback, review, replay, and accepted answer. The memory was complete,
but the conversation was hard to read because system events stood beside human
messages with equal weight.

The Activity view now keeps four conversation messages in the main stream and
groups 34 background events behind **Show history**. The events remain in the
room. The interface changes their place, not their record.

Memory also created a warning. Repetition can look like confidence. Several
attempts at the same question do not make the answer more accurate. The review
must follow the accepted trace back to its evidence.

## Attention

A citation used to move the reader straight to Sources. The jump preserved the
file but broke the reading task. The reader lost the claim that made the source
important.

The preview changes the unit of attention. A person selects **Debt terms** and
stays on Overview. The drawer opens Section 2.02 and shows the exact excess cash
flow passage. **Ask about this** moves the source and anchor into the composer.
**Open full source** completes the longer reading path.

The browser test proved the mechanics. The URL stays on Overview for the first
step. The dialog receives focus. Escape returns focus to the citation. The full
source action opens the same filename and anchor. The test does not prove that a
deal professional prefers the path.

## Agency and tool use

The first complete tool path begins with a debt question. Retrieval places the
Sources of Funds table first. Bonsai writes an answer. A publication guard checks
the citation, amounts, and four debt instruments. Buzz stores the signed event.
The browser renders the result.

Another path begins with failure. The guard retains a rejected answer, the
system retries once, and only the source bound answer reaches the human stream.
The saved workflow evidence passes each transition. The evidence covers one
registered path, not general planning ability.

The benchmark then changes one amount from $900.0 million to $990.0 million.
The faithfulness check fails. The benchmark replaces the mezzanine debt label.
The relevance check fails. A guard that cannot catch either change would be
decoration.

## Rails

The Codex rails made the work inspectable. File edits used patches. Unit tests
checked negative controls. The live browser exposed the JSON rendering defect
and verified the citation journey. The evidence file kept the release decision
closed even when every development metric passed.

The rails also constrain the narrator. I cannot call an agent suggestion a
human label. I cannot call Project Titan a private customer deal. I cannot turn
one saved Bonsai answer into a model accuracy score. The report therefore says
that human validation is pending.

## The unfinished awakening

The benchmark reports Recall at k of 1.0 and mean reciprocal rank of 1.0 across
six development questions. Both passages appear for the one two document case.
One saved Bonsai answer passes separate deterministic grounding and relevance
checks. Three recorded workflows pass. Ten chat traces and 13 agent suggestions
wait in the review interface.

No human has labeled those traces. No blind Bonsai, cloud, and hybrid comparison
has run. No buyer has completed the pricing exercise. The system has more
structure, memory, attention, and controlled action than it had before, but it
has no consciousness and no release claim.

The next entry belongs to the people who review the work.
